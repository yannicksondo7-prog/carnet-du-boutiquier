# Carnet Du Boutiquier

je veux créer un saas qui joue le role de carnet du boutiquier, le saas enrégistre en 3 secondes, une notification au client, un rappel doux automatique. tout est ecrit et horodaté des deux cotés avec un abonnement mensuel des utilisateurs paiement par mobile money où carte bancaire que l'administrateur peut modifier depuis son tableau de bord
